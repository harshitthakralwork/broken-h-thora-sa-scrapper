# SparkXFlow — Environment Configuration Reference

An exhaustive guide to every environment variable in `.env`.

---

## 1. Core Platform Security

| Variable | Default Value | Description & Safety Rules |
| :--- | :--- | :--- |
| `ADMIN_TOKEN` | *Required Secret* | Master authentication token for local dashboard and API access. Must be a high-entropy string (32+ chars). Never share or commit. |
| `DATABASE_URL` | `sqlite:///./sparkxflow.db` | Active database connection. Local SQLite is the single source of truth for all leads, contacts, and CRM pipeline data. |
| `DEBUG` | `false` | Enables verbose stack traces in development. Keep `false` in production. |
| `SECRET_KEY` | *Generated Secret* | Session signing key for cryptographic token verification. |

## 2. Google Sheets Webhook Integration

| Variable | Default Value | Description & Safety Rules |
| :--- | :--- | :--- |
| `GOOGLE_SHEET_ID` | `1jSxjVQUi-RgQzTmOx42nla3JwguIhIkbqNJXlkxPPgk` | Target Google Spreadsheet ID. Enforced strictly by both backend and Apps Script to prevent unauthorized data routing. |
| `SHEETS_WEBHOOK_SECRET` | *Dedicated Secret* | Shared secret between SparkXFlow and Google Apps Script `doPost(e)`. **Never reuse ADMIN_TOKEN.** Apps Script rejects all incoming requests that lack or mismatch this secret. |
| `GOOGLE_SHEETS_WEBHOOK_URL` | `https://script.google.com/macros/s/.../exec` | The Web App deployment URL generated by Google Apps Script. |

## 3. Email Safety Guardrails

| Variable | Default Value | Description & Safety Rules |
| :--- | :--- | :--- |
| `EMAIL_SENDING_ENABLED` | `false` | **Global kill-switch.** When `false`, outbound email transmission is physically blocked across all providers. Keep `false` during internal discovery and testing. |
| `GMAIL_USER` | *Empty* | Optional Gmail account for SMTP outreach. Used only when human approval is explicitly granted. |
| `GMAIL_APP_PASSWORD` | *Empty* | Google App-specific password (16 characters) generated under Google Account Security. |

## 4. Discovery Providers & APIs

| Variable | Default Value | Status & Description |
| :--- | :--- | :--- |
| `WIKIDATA_SPARQL_ENABLED` | `true` | **Live & Free.** Official W3C SPARQL endpoint (`query.wikidata.org`) under CC0 1.0. Requires zero paid tokens. |
| `OVERPASS_PROVIDER` | `public_overpass` | Provider selection: `public_overpass` (free public instances) or `overpass_ch` (Overpass.ch). |
| `OVERPASS_ENDPOINT` | `https://overpass-api.de/api/interpreter` | Target public Overpass endpoint URL. |
| `OVERPASS_CH_API_KEY` | *Empty* | Optional API key for Overpass.ch integration. |
| `GOOGLE_PLACES_API_KEY` | *Empty* | Optional Google Places API key for OutLead bulk discovery. |
| `SERPAPI_API_KEY` | *Empty* | Optional SerpApi key for Google Maps/Search discovery. |
| `OUTLEAD_API_KEY` | *Empty* | Optional OutLead engine key for bulk Maps extraction. |
| `DATA_GOV_IN_API_KEY` | *Empty* | Optional API key for official India Open Government Data (`data.gov.in`). |
| `COMPANIES_HOUSE_API_KEY` | *Empty* | Optional UK Companies House REST API key for overseas corporate discovery. |

## 5. Web Crawler & Safety Sandbox

| Variable | Default Value | Description & Safety Rules |
| :--- | :--- | :--- |
| `WEBSITE_RESEARCH_ENABLED` | `true` | Enables local public website inspection for evidence gathering. |
| `MAX_CRAWL_DEPTH` | `2` | Maximum link depth crawled per verified domain. |
| `MAX_CRAWL_PAGES_PER_DOMAIN` | `5` | Maximum pages fetched per domain to prevent resource exhaustion. |
| `CRAWLER_PACING_SECONDS` | `2.0` | Mandatory delay between requests to the same host. |
| `CRAWLER_USER_AGENT` | `SparkXFlow-Research-Bot/1.0 (+http://127.0.0.1:8000/bot)` | Identifiable User-Agent respecting `robots.txt`. |
| `CRAWLER_ALLOW_PRIVATE_IPS` | `false` | **SSRF Guard.** Prevents requests to localhost, loopback (`127.0.0.1`), private RFC 1918 subnets (`10.0.0.0/8`, `192.168.0.0/16`), or cloud metadata endpoints (`169.254.169.254`). |

## 6. Workflow Automation (n8n Bridge)

| Variable | Default Value | Description & Safety Rules |
| :--- | :--- | :--- |
| `N8N_WEBHOOK_URL` | *Empty* | Webhook trigger endpoint for local or cloud n8n automation pipelines. |
| `N8N_ENABLED` | `false` | Toggle to enable/disable automated event dispatches (`lead.discovered`, `lead.qualified`, `lead.approved`). |
